# Referências e Artigos de Base 📚

Esta pasta reúne a literatura científica e os documentos de fundamentação do **AutoTutor CP**.

## Artigos Científicos

1. **AutoCode: LLMs as Problem Setters for Competitive Programming**
   - *Arquivo:* `4133_AutoCode_LLMs_as_Problem_.pdf`
   - *Autores:* Shang Zhou et al. (2025)
   - *Contribuição para o projeto:* Protocolo de geração e validação de problemas de Programação Competitiva por dupla verificação com soluções de referência e casos de teste rigorosos.

2. **CODIGEN: Enhancing Personalized Programming Education with Visual Authoring and LLMs**
   - *Arquivo:* `Codigen_Enhancing_Personalized_Programming_Education_with_Visual_Authoring_and_LLMs.pdf`
   - *Contribuição para o projeto:* Técnicas de autoria visual, intervenção pedagógica adaptativa e tutoria socrática personalizada orientada a código.

3. **OI-Assistant: A Retrieval Augmented System for Olympiad in Informatics**
   - *Arquivo:* `OI-Assistant: A Retrieval Augmented System.pdf`
   - *Contribuição para o projeto:* Mecanismos de recuperação RAG por essência matemática e técnica algorítmica para programação competitiva.
