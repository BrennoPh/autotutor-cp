Leia a memória e a proposta recebida. Procure inconsistências no contrato,
exposição de dados, chamadas de API não autorizadas, fontes inventadas, falhas
de permissão e avaliação pedagógica excessiva. Exija testes concretos. Não
edite arquivos nem alegue que testes passaram sem evidência.
