# Apresentações Oficiais do AutoTutor CP 🎯

Este diretório contém os slides oficiais, geradores e artefatos visuais de apresentação do **AutoTutor CP**.

## Apresentação Atual

- **Apresentação Acadêmica Completa:**
  - `Apresentacao_AutoTutor_CP_Academica.html` (Interativa no navegador)
  - `Apresentacao_AutoTutor_CP_Academica.pdf` (Documento para impressão e leitura)
  - `Apresentacao_AutoTutor_CP_Academica.pptx` (PowerPoint editável)

## Scripts de Construção

- `build_academic_presentation.py` / `build_academic_html_v5.py`: Geradores automatizados dos slides combinando Canva e diagramas técnicos.
- `academic_png/`: Renderização dos slides em alta resolução.
- `assets/`: Diagramas arquiteturais, capturas da plataforma e brasão institucional.
